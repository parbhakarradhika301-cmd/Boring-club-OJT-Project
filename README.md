# Boring Club - OJT Project

## 📖 About the Project

The **Boring Club** is a front-end web application developed as part of our **On-the-Job Training (OJT)** program. The project focuses on applying web development concepts by creating a responsive, user-friendly, and interactive website using modern front-end technologies.

This project helped us strengthen our understanding of HTML, CSS, and JavaScript while working on a real-world college project.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## ✨ Features

- Responsive website design
- Modern and clean user interface
- Interactive JavaScript functionality
- Mobile-friendly layout
- Easy navigation
- Organized project structure
